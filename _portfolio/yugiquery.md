Full Python package for querying and displaying Yu-Gi-Oh! data from the <a href="http://yugipedia.com" target="_blank">yugipedia</a> database. pip-installable CLI tool. Features Discord/Telegram bots, ReadTheDocs documentation, GitHub Actions CI/CD, custom nbconvert HTML templates, Git filters, data pipeline with changelog tracking. Built on pandas, matplotlib and Git.
